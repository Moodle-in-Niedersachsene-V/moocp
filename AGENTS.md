# moocp

Desktop-App (Flutter, Windows und Linux), die Lehrkräften per MCP einen Moodle-Zugang für KI-Werkzeuge bereitstellt, mit Skills als Wissensschicht.

## Immer relevant

- **Vor jeder Arbeit an einem Issue die Zuweisung prüfen** (Anfang der [CLAUDE.md](CLAUDE.md)): Nur am eigenen oder an einem nicht zugewiesenen Issue arbeiten, dieses zuerst sich zuweisen; ist es jemand anderem zugewiesen, anhalten, bis die Person am Rechner bestätigt, dass sie mit dem anderen gesprochen hat.
- Kanonische Regeln: [CLAUDE.md](CLAUDE.md) – Regeln für die Dokumentation, Anforderungen A1–A11 (Datenschutz, Zugangsdaten, Schreiben nur nach Freigabe) gelten ausnahmslos, dazu der Index der Entscheidungen E1–E36 und die Arbeitsregeln. Die CLAUDE.md gilt für jedes KI-Werkzeug, auch für Codex.
- Entscheidungen mit Begründung: [docs/adr/](docs/adr/); Fachsprache: [GLOSSARY.md](GLOSSARY.md).
- Vor jedem Edit die Datei lesen. Bei Funktionsänderungen die Aufrufer suchen.
- Aufbau, Bauen und Prüfen: [README.md](README.md), Teil 4.
