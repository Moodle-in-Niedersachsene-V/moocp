# Beispiel-Plugin

Dieser Skill gehört zum Beispiel-Plugin von moocp. Er zeigt, wie ein Plugin einen Skill mitbringt, der immer installiert wird; eine eigene Aufgabe hat er nicht.

- Das Werkzeug `beispiel_echo` gibt seinen Text zurück. Damit lässt sich prüfen, ob das Plugin läuft.
- Alle Werkzeuge des Plugins beginnen mit `beispiel_`. Was sie tun, steht in ihrer Beschreibung.
- Moodle erreichst du nur über die Werkzeuge von moocp, nie an der App vorbei.
