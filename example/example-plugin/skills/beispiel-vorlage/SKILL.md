# Vorlage für einen wählbaren Skill

Dieser Skill gehört zum Beispiel-Plugin von moocp. Er wird nur installiert, wenn die Lehrkraft ihn im Dialog „KI-Werkzeuge einrichten“ wählt, und zeigt, wie ein wählbarer Skill aussieht.

Ein Skill darf weitere Dateien mitbringen; sie liegen in seinem Ordner, etwa unter `references/`. Diese Vorlage hat eine: [references/hinweis.md](references/hinweis.md).
